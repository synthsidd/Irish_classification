# 🌸 Iris Flower Classification using Machine Learning

This project uses **Python** and **Machine Learning algorithms** to classify iris flowers into three species:
- **Setosa**
- **Versicolor**
- **Virginica**

The dataset used is the classic **Iris dataset**, which comes built-in with `scikit-learn`.  
The program performs **Exploratory Data Analysis (EDA)** and applies **three supervised learning algorithms**:
1. Decision Tree  
2. Support Vector Machine (SVM)  
3. k-Nearest Neighbors (KNN)

---

## 📘 Project Overview

### ✳️ Objectives
- Understand the dataset through **EDA**.
- Train multiple **supervised models**.
- Evaluate and compare their performance using accuracy, precision, recall, and F1-score.

### 🧩 Dataset Information
The dataset contains **150 samples** with **4 features**:
| Feature | Description | Unit |
|----------|--------------|------|
| Sepal Length | Length of the sepal | cm |
| Sepal Width  | Width of the sepal  | cm |
| Petal Length | Length of the petal | cm |
| Petal Width  | Width of the petal  | cm |

Each flower belongs to one of the following species:
- **Iris-setosa**
- **Iris-versicolor**
- **Iris-virginica**
